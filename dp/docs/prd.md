# DP 产品需求

> 状态：当前实现基线
> 更新时间：2026-09-02
> 本次为不兼容重构，不要求兼容已上线服务或旧数据库。

## 1. 产品目标

DP 用于在内网统一管理服务安装包、SSH 主机、服务实例和模型。用户只注册一次物理或虚拟主机，即可在该主机上创建多个服务实例；服务的业务 API 由外部网关直接访问，不经过 DP。

## 2. 核心流程

1. 上传带 DP 配置和生命周期脚本的服务安装包。
2. 注册主机，填写 SSH 地址、端口、用户和密码；保存动作先完成连接校验，通过后原子保存主机与校验结果。
3. 在服务管理中选择主机、服务类型和安装目录，创建服务实例。
4. 编辑实例配置并查看当前包模板差异。
5. 安装、启动、停止、健康检查、查看日志或重置服务。
6. 可选择主机上传大模型，模型不绑定具体推理服务。

## 3. 主机管理

- 主机字段：名称、IP、SSH 端口、SSH 用户、SSH 密码、备注、架构、最近校验时间。
- 同一账号的 `IP + SSH 端口` 唯一；同一台主机无需因部署不同服务而重复注册。
- 密码只以密文保存，列表仅显示是否已设置密码。
- SSH 校验必须验证连接、主机指纹、架构和远端临时目录写权限。
- 新建主机以及修改 IP、端口、SSH 用户或密码时必须先校验后保存；校验失败不得创建或覆盖主机记录。
- 仅修改名称或备注时保留既有校验结果；修改连接信息时校验并保存新的校验结果。
- 支持 schema v1 JSON 导入导出；导入按 `IP + SSH 端口` 原子 upsert。
- 主机仍有关联服务实例或未删除模型时禁止删除。

## 4. 安装包管理

- 安装包按账号和 `service_type` 管理，每次上传形成不可变版本。
- 包内必须且只能包含一种支持的配置文件，并包含安装、启动、停止和日志脚本。
- 上传时校验归档路径、配置格式和脚本完整性。
- 可以切换当前版本；切换只影响后续安装。
- 当前版本或已被服务实例安装引用的版本禁止删除。
- 删除服务类型前必须删除全部关联服务实例。

## 5. 服务实例管理

- 服务实例字段：名称、`host_id`、服务类型、安装目录、备注和标签。
- 创建时主机与安装包必须属于同一账号。
- 同一主机的安装目录唯一，不允许两个实例共享目录。
- 同一主机允许部署多个不同服务，也允许同类服务使用不同安装目录部署多份。
- 已安装实例禁止修改主机、服务类型和安装目录；需先重置。
- 删除服务实例不会删除主机；已安装或有运行中操作时禁止删除。
- 标签绑定服务实例，用于服务列表、操作列表和总览筛选。

## 6. 配置、端口与生命周期

- 未保存实例配置时读取当前安装包配置作为模板。
- 包版本变化后，同时展示实例当前配置与新包模板，并高亮差异；不得静默覆盖实例配置。
- 每次保存或回滚创建不可变配置修订。
- 配置中的 `port` 或 `server.port` 是健康检查端口，安装后记录为 `health_port`，仅供 DP 使用。
- 配置中的 `api_port` 是业务 API 端口，展示给用户和 LiteLLM 等外部网关使用。
- 生命周期操作按服务实例互斥，异步记录阶段、输出、结果和错误码。
- 日志页面展示当前服务实例的包内日志脚本输出；一个包管理多个容器时，应由该脚本汇总或明确选择输出。
- DP 只请求 `http://<主机IP>:<health_port>/healthz`，HTTP 200 且 JSON 状态为 `ok` 才视为健康。

## 7. 模型管理

- 第一阶段支持将 `.tar.gz` 直接分片中转到选定主机，不在 DP 数据盘保留完整副本。
- 支持断点续传、安全路径校验、远端解压、进度日志、失败重试和删除。
- 上传过程中可以关闭弹窗并切换 DP 页面，但不能刷新或关闭当前浏览器标签页；中断后重新选择同一文件继续。
- 模型通过 `host_id` 关联主机，可被多个 vLLM/SGLang 实例引用，DP 不自动修改推理配置。
- 在线 ModelScope/Hugging Face 下载属于后续阶段，默认优先 ModelScope。

详细设计见[模型管理文档](model-management.md)。

## 8. 账号、RBAC 与资源交接

- 权限使用固定目录和可管理角色；所有 API 默认拒绝，后端检查权限和 `own/all` 数据范围。
- 管理员可管理全部账号资源，普通角色只访问授权范围。
- 账号资源交接一次性转移安装包、主机、服务实例、模型及相关配置和任务。
- 存在运行中任务或目标账号唯一键冲突时整批回滚，不允许部分交接。
- 删除账号前必须禁用、撤销会话并完成资源交接。

## 9. 审计、操作与通讯

- 登录、授权拒绝、账号、角色、安装包、主机、服务实例、模型和跨账号操作写入审计。
- 审计保存资源名称、主机 IP、账号和服务类型快照；删除资源后仍可查询。
- 操作中心按操作者、所属账号、动作、状态、标签、时间和关键字筛选。
- 管理员可创建关联安装包、主机或服务实例的通讯事项；资源删除后显示为失效引用。
- SSH 指纹变化、连续登录失败、跨账号变更和资源删除产生高风险通知。

## 10. 非功能要求

- 单文件上传默认最大 100 GiB；模型采用分片协议。
- PostgreSQL 是唯一数据库；生产由 Docker Compose 部署 DP 与 PostgreSQL。
- 离线包必须包含 DP 和 PostgreSQL 镜像，目标机无需联网。
- 前端构建、Go 单元测试、空库迁移和 PostgreSQL 集成测试必须通过。
- API 契约以 [OpenAPI](../api/openapi.yaml) 为准，架构和模块职责见[架构设计](architecture.md)。
